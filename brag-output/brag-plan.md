# SwarnLanka AI — Brag Plan

## 9-Question Rubric

1. **What is the app?**
   AI-powered civic intelligence platform that transforms citizen reports (photo UploadFile + text + GPS) into verified, prioritized, and routed civic incidents.

2. **Funniest / most impressive claim?**
   "12 reports = 1 pothole. 73m away, same Group #2, priority bumped 71 -> 77." + "P1 Critical in seconds, not days."

3. **Visual hook?**
   Gold gradient hero (gold-gradient #d4af37 -> #92400e, glass cards, charcoal nav) + Leaflet OSM colored markers (red/orange/amber/green) + UploadFile drag-drop.

4. **What to show from actual UI?**
   Landing hero + Report page UploadFile + AI card (P2 High) + Dashboard Priority Queue + Duplicate Groups + Map with popups. Must show real UI, not abstract.

5. **Shortest satisfying video?**
   20 seconds. Hook 2s + Reveal 3s + Highlights 10s (3 beats) + Outro 5s = 20s.

6. **Tone?**
   Preset: polished (elegant, civic-serious) for judges + cinematic for donor cut + app-store for vertical. Freeform: "quiet premium product film for civic trust"

7. **Audio?**
   Warm corporate bed (Happy Beats / Business Moves), low music bed with final fade, one dry logo hit, motion-matched SFX for card reveals, beat-sync for queue/markers.

8. **Share caption?**
   "SwarnLanka AI: Citizen photo -> AI priority in seconds. 12 reports, 1 incident. Live: swarn-lanka-...vercel.app"

9. **User flow worth showing?**
   Entry: Open /report -> Upload photo + type "huge pothole near college gate" + Use Current Location -> Key action: Click Analyze with AI -> see road_damage 0.94 P2 High 71 -> Result: Click Submit -> see ID # + Group # -> Dashboard shows Priority Queue sorted -> Map shows red marker.

## Creative Angle
Quiet premium civic product film. No jokes, no chaos. Gold minimal, charcoal nav, ivory background. Show the loop is complete and auditable.
